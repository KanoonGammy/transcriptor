# 🎙️ Transcriptor Pro

**Transcriptor Pro** คือเว็บแอปพลิเคชันสำหรับถอดเสียงพูดเป็นข้อความอัตโนมัติ (Speech-to-Text) คุณภาพสูง ขับเคลื่อนด้วยโมเดล **ElevenLabs Scribe** (รองรับทั้ง `scribe_v1` และ `scribe_v2`) ออกแบบมาเพื่อการทำงานเป็นทีมอย่างปลอดภัย พร้อมระบบจัดสรรสิทธิ์ผู้ใช้, ประวัติกิจกรรม (Audit Log), การส่งออกเอกสาร Word/PDF/Text ภาษาไทย 100%, และระบบบริหารพื้นที่จัดเก็บไฟล์เสียงอัตโนมัติ

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **ระบบความปลอดภัยและการควบคุมสิทธิ์ (Role-Based Access Control)**
   - ระบบ Login แบบปลอดภัย (JWT + HTTP-Only Cookie + Bcrypt)
   - **แอดมินเท่านั้นที่เป็นคนสร้างบัญชีผู้ใช้งานได้**: ปิดระบบสมัครสมาชิกสาธารณะเพื่อความปลอดภัยสูงสุดขององค์กร
   - สิทธิ์แบ่งเป็น **Admin** (จัดการผู้ใช้, ดูบันทึกกิจกรรม, ปรับตั้งค่าระบบ, ล้างไฟล์ดิสก์) และ **User** (อัปโหลดและถอดเสียง)

2. **เชื่อมต่อ ElevenLabs Speech-to-Text (Scribe)**
   - ตั้งค่าและเปลี่ยน **ElevenLabs API Key** ได้โดยตรงจากหน้า **ตั้งค่าระบบ (Settings)** ในเว็บแอป ไม่ต้องแก้โค้ด
   - มีปุ่ม **"ทดสอบการเชื่อมต่อ (Test Connection)"** แสดงสถานะความถูกต้องของคีย์, แพ็กเกจสมาชิก (Tier), และโควต้าอักขระที่ใช้งาน
   - รองรับการแยกผู้พูดอัตโนมัติ (**Speaker Diarization**)
   - สามารถระบุภาษา (เช่น ภาษาไทย, ภาษาอังกฤษ, ภาษาจีน, ญี่ปุ่น) หรือตั้งตรวจจับภาษาอัตโนมัติ (Auto Detect)

3. **อัปโหลดและประมวลผลในพื้นหลัง (Background Task)**
   - Drag & Drop ไฟล์เสียง/วิดีโอ (MP3, WAV, M4A, MP4, WebM, OGG, FLAC, AAC)
   - ไม่ทำให้เบราว์เซอร์ค้างระหว่างประมวลผลไฟล์ขนาดใหญ่ มีระบบ Real-time Status Polling

4. **เครื่องเล่นเสียงและตัวแปลงบทสนทนาอัจฉริยะ (Interactive Transcript Player)**
   - มี Audio Player ติดแถบด้านบน ปรับความเร็วเสียงได้ (0.75x, 1x, 1.25x, 1.5x, 2x)
   - **คลิกที่เวลาหรือประโยคใดๆ** เพื่อกระโดดไปยังช่วงเวลานั้นของเสียงได้ทันที
   - แถบข้อความจะไฮไลต์อัตโนมัติ (**Active Segment Highlight**) ตามเวลาที่เสียงกำลังเล่น
   - **เปลี่ยนชื่อผู้พูดได้ตามใจชอบ**: สามารถแก้จาก "speaker_0" เป็น "คุณสมชาย" หรือ "พิธีกร" และเมื่อกดบันทึก เอกสาร Word, PDF, Text จะอัปเดตเป็นชื่อใหม่ให้ทันที!

5. **ส่งออกเอกสารคุณภาพระดับมืออาชีพ 3 รูปแบบ**
   - 📄 **Microsoft Word (.docx)**: จัดหน้าสวยงาม มีหัวข้อ กล่องข้อมูลสรุป (วันที่, ความยาว, ผู้พูด) พร้อมป้ายชื่อผู้พูดและช่วงเวลา
   - 📕 **Adobe PDF (.pdf)**: ใช้ฟอนต์มาตรฐานภาษาไทย **Sarabun (TH Sarabun)** อักษรคมชัด ไม่เป็นสี่เหลี่ยม/ต่างดาว พร้อมหมายเลขหน้าอัตโนมัติ
   - 📝 **Plain Text (.txt)**: เข้ารหัสแบบ UTF-8 with BOM สามารถเปิดบนโปรแกรม Notepad ของ Windows ได้ทันทีโดยสระไม่เพี้ยน

6. **บันทึกกิจกรรมในเซิร์ฟเวอร์ (Activity Logs / Audit Trail)**
   - บันทึกทุกความเคลื่อนไหว: ใครล็อกอิน, ใครอัปโหลดไฟล์อะไร, ใครเริ่มถอดเสียง, ถอดเสร็จเมื่อไหร่, ใครดาวน์โหลดเอกสารประเภทไหน, ใครเปลี่ยนการตั้งค่า, ใครสร้าง/ลบผู้ใช้
   - บันทึกพร้อมวันเวลา, Username, IP Address และรายละเอียด
   - ผู้ดูแลระบบสามารถค้นหา กรอง และส่งออกเป็นไฟล์ **CSV** ได้ใน 1 คลิก

7. **ระบบบริหารพื้นที่จัดเก็บไฟล์ชั่วคราว (Storage Retention & Auto Cleanup)**
   - ดูปริมาณพื้นที่ดิสก์ที่ใช้ไปแบบ Real-time
   - กำหนดนโยบายลบไฟล์เสียงเก่าอัตโนมัติ (เช่น ลบหลัง 7 วัน, 24 ชม., หรือลบทันทีหลังถอดเสียงเสร็จ) เพื่อป้องกันฮาร์ดดิสก์เซิร์ฟเวอร์เต็ม
   - บทถอดความและข้อความในฐานข้อมูลจะคงอยู่อย่างถาวร แม้ไฟล์เสียงต้นฉบับจะถูกล้างออกไปแล้ว

## 💡 เรื่องพื้นที่จัดเก็บไฟล์ชั่วคราว (Storage Explanation)

> **คำถาม**: *"เรื่องไฟล์จัดเก็บ ชั่วคราว ผมไม่มั่นใจว่าเราต้องมีพื้นที่สำหรับจัดเก็บไหม?"*

### คำตอบและแนวทางการออกแบบของระบบ:
1. **จำเป็นต้องมีพื้นที่ชั่วคราวระหว่างที่ผู้ใช้อัปโหลด**:
   - เมื่อผู้ใช้อัปโหลดไฟล์เสียง (เช่น ไฟล์ MP3/WAV ขนาด 20MB - 200MB) ตัวเว็บเซิร์ฟเวอร์จะต้องบันทึกไฟล์นั้นลงในโฟลเดอร์ `data/uploads/` ชั่วคราว เพื่อเตรียมส่งต่อไปยัง ElevenLabs Scribe API และเพื่อให้ผู้ใช้เปิดฟังย้อนหลังในเครื่องเล่นเสียงของเว็บได้
2. **ข้อความที่ถอดเสร็จแล้ว (Transcript Text & Segments)**:
   - ผลลัพธ์ทั้งหมดถูกเก็บลงในฐานข้อมูล SQLite (`data/transcriptor.db`) ซึ่งกินพื้นที่น้อยมากๆ (ประมาณ 50KB - 100KB ต่อไฟล์เสียง 1 ชั่วโมง) ดังนั้นข้อความบทถอดสามารถเก็บไว้ได้หลายหมื่นรายการโดยไม่เปลืองพื้นที่
3. **ระบบตัดกังวลเรื่องฮาร์ดดิสก์เต็ม (Automated Retention Policy)**:
   - ระบบนี้สร้างระบบ **Auto-Cleanup** มาให้พร้อม โดยแอดมินสามารถเข้าไปที่หน้า **Settings** และเลือกนโยบายล้างไฟล์เสียง:
     - **ลบไฟล์เสียงอัตโนมัติหลัง 7 วัน** *(ค่าเริ่มต้นที่แนะนำ)*: ให้เวลาผู้ใช้ 7 วันในการฟังตรวจทาน เมื่อครบกำหนด ระบบจะลบไฟล์เสียงทิ้งเพื่อคืนพื้นที่ดิสก์ให้เซิร์ฟเวอร์ 100% แต่ข้อความบทถอดและไฟล์ Word/PDF ยังคงดาวน์โหลดได้ตลอดไป!
     - **ลบไฟล์เสียงทันทีเมื่อถอดเสียงเสร็จ (Immediate)**: สำหรับเซิร์ฟเวอร์ที่มีพื้นที่ดิสก์จำกัดมาก
     - **ปุ่ม "ล้างไฟล์เสียงเก่าทันที (Clean Up Now)"**: แอดมินสามารถกดปุ่มเพื่อล้างไฟล์เสียงทั้งหมดที่ถอดความเสร็จแล้วได้ทันทีทุกเมื่อ

## 🚀 วิธีการติดตั้งและรันใช้งาน (Getting Started)

### ความต้องการของระบบ (Prerequisites)
- Python 3.10 ขึ้นไป
- Git

### 1. วิธีรันบน Windows (ง่ายที่สุด)
ดับเบิลคลิกไฟล์:
```cmd
start.bat
```
*(ระบบจะสร้าง Virtual Environment ติดตั้งโมดูล และเปิดเว็บเซิร์ฟเวอร์ให้อัตโนมัติ)*

### 2. วิธีรันผ่าน Terminal (Windows / macOS / Linux)

```bash
# 1. ติดตั้ง Dependencies
pip install -r requirements.txt

# 2. เริ่มต้นรันเซิร์ฟเวอร์
python main.py
```

เมื่อรันสำเร็จ ให้เปิดเว็บเบราว์เซอร์ไปที่:
👉 **`http://localhost:16872`**

## ⚙️ ขั้นตอนใส่ ElevenLabs API Key

1. เข้าสู่ระบบด้วยบัญชีแอดมิน `admin`
2. ไปที่เมนูด้านซ้าย **"ตั้งค่าระบบ & พื้นที่ (Settings)"**
3. นำ API Key ที่ได้จาก [elevenlabs.io](https://elevenlabs.io/) มาวางในช่อง **API Key**
4. กดปุ่ม **"ทดสอบการเชื่อมต่อ"** เพื่อตรวจเช็กความถูกต้อง
5. กดปุ่ม **"บันทึกการตั้งค่าทั้งหมด"**

## 🐙 วิธีอัปโหลดขึ้น GitHub (Push to GitHub)

หากคุณสร้าง Repository ใหม่บน GitHub แล้ว ให้รันคำสั่งต่อไปนี้ในโฟลเดอร์โปรเจกต์:

```bash
# 1. เริ่มต้น Git Repository
git init

# 2. เพิ่มไฟล์ทั้งหมด (ไฟล์รหัสผ่านและไฟล์เสียงจะถูกยกเว้นตาม .gitignore)
git add .

# 3. บันทึก Commit แรก
git commit -m "feat: Initial commit of Transcriptor Pro with ElevenLabs Scribe and Admin Auth"

# 4. ตั้งชื่อ Branch หลักเป็น main
git branch -M main

# 5. เชื่อมต่อไปยัง Repository บน GitHub ของคุณ (เปลี่ยน URL เป็นของคุณ)
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPOSITORY_NAME>.git

# 6. Push ขึ้น GitHub
git push -u origin main
```

## 🛡️ ความปลอดภัยของข้อมูล (Security Best Practices)

- ไฟล์ `.gitignore` ถูกตั้งค่าให้ **ไม่นำ** ไฟล์เสียงใน `data/uploads/`, ฐานข้อมูล `data/transcriptor.db`, และไฟล์ `.env` ขึ้นไปบน GitHub เด็ดขาด ข้อมูลของคุณและ API Key จึงปลอดภัย 100%
- รหัสผ่านของผู้ใช้งานทุกคนถูกแฮชด้วยอัลกอริทึม **Bcrypt**
- ปิดระบบเปิดรับผู้ใช้ทั่วไป มีเฉพาะแอดมินที่สร้างบัญชีได้เท่านั้น
